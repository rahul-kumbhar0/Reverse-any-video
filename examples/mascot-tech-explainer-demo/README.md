# Demo: a reel rendered in the "mascot-tech-explainer" style

End-to-end proof of the plugin: the style was reverse-engineered from a real reel
(`skills/generated/mascot-tech-explainer/`), then this 30s video about the elevator
door-close button was generated in that style — new mascot, new topic, same visual grammar.

```bash
npm install
npx remotion render Main out/reel.mp4
```
