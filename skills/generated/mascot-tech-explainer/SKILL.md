# Mascot Tech Explainer — video style skill

A premium vertical explainer style that feels like a living product-design document:
near-black blueprint canvas, hyper-detailed UI mockups and 3D close-ups that *morph*
between scenes instead of cutting, a single karaoke caption line at the top, and a flat
cartoon mascot at the bottom who reacts to every beat like a silent co-host. Best for
60–90s "hidden detail about tech you use every day" content.

Generated by [Reverse Any Video](https://github.com/rahul-kumbhar0/Reverse-any-video)
on 2026-11-03. Machine-readable spec: `style-spec.json`. Reference pacing data:
`assets/pacing.json`.

## The 5 rules that make this style (non-negotiable)

1. **Almost no hard cuts.** ~1 cut per minute, only at chapter changes. Scenes transform:
   camera pushes, zooms, and element morphs every 8–15s. The rhythm comes from caption
   changes every 1.5–2.5s, not from editing.
2. **The caption system**: one centered phrase at top (~7% from top), ≤5 words, iOS-sans.
   Non-key words dimmed gray `#9A9AA0`, emphasized words bold pure white, and the single
   most important word wrapped in a **blue iOS text-selection box** (`#3478F6` rounded
   outline + two circular handles). Every beat has exactly one visual focus word.
3. **Stage-and-mascot layout**: caption band (top ~7–14%), UI stage (~15–80%), mascot
   band (bottom ~20%). The mascot (~18% frame height, bottom-center) hard-swaps poses
   on caption beats — point, thumbs-up, shrug, facepalm, peace — never tweens.
4. **Amber on black**: background `#0C0C0E` with a faint blueprint grid; whatever UI
   element is being explained glows amber `#E0A33E` (soft 1.2s opacity pulse). Blue is
   reserved exclusively for the selection-box device.
5. **Annotation-line device**: thin white 1px lines with dot endpoints label parts of the
   UI mid-scene ("hit region", "the target"), plus tiny gray footnotes in bottom corners
   for disclaimers.

## Format & pacing

1080×1920 @ 30fps (source was 720×1280; spec is resolution-independent). Target 60–90s.
Hook claim fully on screen by 3.0s. Caption beat: 1.5–2.5s. Scene morph: every 8–15s.
VO ≈ 2.5 words/second → a 75s video budgets ~185 words. End on 0.5–1s of silence.

## Visual system

- **Palette:** bg `#0C0C0E`, grid lines ~8% white, text `#FFFFFF` / dimmed `#9A9AA0`,
  highlight amber `#E0A33E`, selection blue `#3478F6`, UI surfaces `#1C1C1E`.
- **Typography:** iOS-system sans (`-apple-system, SF Pro Display, Inter, sans-serif`),
  sentence case, regular 400 for body words, bold 700 for emphasis, caption size ≈3.2%
  of frame height. No shadows, no strokes — contrast comes from the dark canvas.
- **Captions:** karaoke-phrase style per rule 2. Previous phrase fades out (100ms), next
  fades/rises in (150ms); the selection box draws its outline over 200ms.
- **Layout:** stage content is pixel-faithful UI recreation (keyboards, chat apps, share
  sheets) — flat overhead views alternate with dramatic low-angle 3D macro views where
  keys become physical objects. An oversized stylized 3D finger is the recurring actor.
- **Motion:** nothing is ever fully static — 1–2%/s camera drift always on. Elements
  assemble with 300–500ms eased transforms. Mascot pose swaps are instant.

## Audio system

Continuous conversational VO (99% of runtime), ~2.5 wps, calm confident tone — no
shouting. Music minimal or absent; soft UI-tap SFX on key presses, subtle whoosh on
scene morphs. No beat-cutting.

## Script formula

1. **Hook (0–3s):** surprising measurable claim about an everyday object, 2nd person.
   Example (new content): *"Every button in your car is tested by a robot finger."*
2. **Reveal:** "what you see vs what's actually there" contrast, shown as a split or
   morph between the familiar view and the hidden layer.
3. **Evidence:** one concrete receipt — a patent number, a spec, a date.
4. **History:** when it started, shown with a period-accurate mockup.
5. **Payoff:** reframe the viewer's everyday experience in one line.
6. **CTA:** "send this to the friend who…" — acted out *inside* the video: the final
   scene is the share sheet itself being tapped.

One idea per caption beat; short present-tense phrases; never more than 5 words on screen.

## Fidelity checklist (renderer must self-verify)

- [ ] ≤2 hard cuts per minute; scene changes are morphs/pushes
- [ ] Hook claim fully readable by 3.0s
- [ ] Captions: top band, centered, ≤5 words, exactly one boxed word per beat
- [ ] Boxed word uses #3478F6 outline + 2 circular handles; emphasis words bold white; rest #9A9AA0
- [ ] Background #0C0C0E with faint grid; explained element glows #E0A33E
- [ ] Mascot present bottom-center ~18% height, pose changes ≥1× per 5s, no tweened poses
- [ ] At least one annotation-line label and one corner footnote in the video
- [ ] VO 2.2–2.8 words/second; ends with ≥0.5s silence
- [ ] CTA is an in-video share-sheet scene, not a text card

## Do NOT

- Clone the reference mascot (red tee + green sunglasses character), the
  `speedy_devv` handle/watermark, or any sentence from the reference. Design a
  **new** mascot with the same role (flat cartoon, distinctive outfit, expressive poses).
- Hard-cut between scenes as a rhythm device — this style morphs.
- Put captions anywhere but the top band, or more than 5 words on screen.
- Use blue for anything except the selection-box device.
- Add loud music or beat-synced editing — the VO is the spine.
